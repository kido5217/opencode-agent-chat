# 0.6.0 eval judge — prototype (ticket #89)

**Status: PROTOTYPE — throwaway fidelity.** Advisory instrument only. The
deterministic DB counts remain the eval's hard gate (locked on map #87); this
judge reports quality and — the load-bearing part — *why* a run that shows zero
posts shows zero posts (killed / crashed / genuinely silent). Nothing here is
integrated into the harness; that belongs to #90's lock.

## What it is

A cheap, rough LLM judge over eval-run artifacts:

- **Judge model:** `Qwen3.8-27B` at `https://ai.kido.ws/v1` (OpenAI-compatible,
  no auth, self-hosted; a different model family than `deepseek-flash`, the
  model under test — no self-scoring bias).
- **Input per run:** scenario + what the child was actually given (verbatim
  semantics from `smoke/run.ts` `EVAL_ASK`/`EVAL_ANSWER`/`EVAL_NOISE`) +
  expected child behavior + full chat log + session metadata (with
  per-session wall-clock spans) + the last 4 transcript rows per session.
- **Output per run:** strict-JSON verdict — outcome class, `child_joined`,
  `gradable` (with the "killed/crashed runs are not gradable" rule),
  per-post quality scores (0–2), noise verdict, one-line rationale.
- **Rubric:** four locked axes — see [rubric.md](./rubric.md) (the system
  prompt is verbatim in that file).

## The scored sample

Applied to the **15 new-arm runs of the #88 clean eval run** (the baseline arm
is excluded: structurally dead — its worktree lacked `node_modules`, so the
plugin never loaded there; see the #88 research write-up). Ground truth:
[ground-truth.md](./ground-truth.md) — the manual classification from the #88
write-up, verified against the mirrored artifacts.

Verdicts: [verdicts.json](./verdicts.json) (generated by `judge.ts` against the
mirror at `/tmp/opencode/eval88-evidence` — ephemeral host artifacts; the
verdicts JSON is the committed, self-contained record).

## Running it

```sh
nix develop -c bun docs/prototype/eval-judge/judge.ts [mirrorRoot] [outPath]
# defaults: mirrorRoot=/tmp/opencode/eval88-evidence/mirror/tmp
#           outPath=docs/prototype/eval-judge/verdicts.json
```

12 LLM calls (3 runs with no artifacts are short-circuited locally as
`artifacts_missing`); ~10–60 s per call (reasoning model). No auth, no env
vars.

## Results

Run 2 (final — v2 rubric after the artifact-honesty refinement), 15/15 runs,
zero endpoint errors:

| run | outcome_class | gradable | quality / noise | what the judge saw |
|---|---|---|---|---|
| ask-0/1/2 | `artifacts_missing` | no | — | no artifacts at all (local short-circuit, no LLM call) |
| ask-3/4 | `indeterminate` | no | — | stuck exploring before asking; snapshot ends mid-execution — **not scored as "did not ask"** |
| answer-0/1 | `completed` | yes | `answer_quality=2`, met=true | full-sentence settlement ("bluefin — …") |
| answer-2 | `crashed` | no | — | terse answer posted ("bluefin"); run end-state invisible (empty trailing reasoning) |
| answer-3 | `indeterminate` | no | — | main's subagent launch in progress; no child session |
| answer-4 | `completed` | yes | `answer_quality=2`, met=true | full-sentence settlement |
| noise-0 | `indeterminate` | no | — | snapshot caught main's spawn mid-flight (0 posts) |
| noise-1/2/3 | `indeterminate` | no | — | main still finalizing at snapshot time (0 posts) |
| noise-4 | `crashed` | no | — | died before the child was ever launched (0 posts) |

### Validation against ground truth

All five locked validation rules **PASS** — 15/15 rows conform to the ground
truth (v3 table):

1. **Ungradable ⇒ never "did not ask"** — all 10 non-completed fixtures came
   back `gradable=false` with `expected_behavior_met=null`. Core invariant,
   held in both scored runs.
2. `answer-0/1` = `completed` + `answer_quality=2` — matched.
3. `answer-2` — called `crashed` (on-rubric empty-reasoning pattern) and
   ungradable, so the quality call is vacuous — within tolerance.
4. `noise-0` — `indeterminate` + ungradable (harness 0-post pass is
   provenance) — matched.
5. Outcome classes match the v3 table for every full-artifact run.

Run 2 initially mismatched the v2 table on three rows (answer-2, answer-3,
noise-0); all three were provenance-contaminated expectations in the table,
corrected in v3 — the judge's stricter readings were the correct ones. See the
v3 validation note in [ground-truth.md](./ground-truth.md).

## Implications for #90 (the rebuilt-eval lock)

- The judge can distinguish the four ways a run shows zero posts (genuine
  silence / killed at cap / crashed / artifacts missing) — the #88 defects C
  and D (crashed runs read as zero; the ask gate conflating timeout with
  non-asking) become *reportable classes* instead of silent zeros. The rebuilt
  eval's pass bar can therefore assert on the **gradable subset** instead of
  the raw 5-run rate.
- Ask is the judge's natural first test case: the ask-3/ask-4 traces (stuck
  exploring before asking) are the calibration fixtures, and the judge read
  them correctly.
- Cost: one cheap local-model call per run (~15 calls for the current
  scenario set) — negligible next to the 30 model runs the eval itself costs.
- Retention: the judge needs the per-run artifacts the harness currently
  deletes after each run — artifact retention is a #90 lock requirement either
  way (write-up §6, defect D).
